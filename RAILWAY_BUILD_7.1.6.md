# Railway build · V7.1.6

V7.1.6 yalnız frontend qaimə redaktorunu genişləndirir; V7.1.4-də düzəldilmiş Java compile fix və V7.1.5 backend/eFP məntiqi saxlanılıb.

## Yeni qaimə redaktoru
- Saytda Excel A:Y 25 sütun bir cədvəldə göstərilir.
- Sətir əlavə etmə tam A:Y sətri yaradır.
- A–H qaimə məlumatları bütün mal sətirlərində avtomatik sinxron saxlanılır.
- I–Y mal/xidmət sahələri sətir üzrə müstəqildir.
- Enter ilə aşağı keçid və son sətirdə avtomatik yeni sətir yaradılması var.
- Excel-dən tab/newline formatında çoxxanalı paste dəstəklənir.
- O/R/W/Y avtomatik hesab məntiqi və manual override qorunur.

Railway üçün Dockerfile və build strukturu əvvəlki compile-fix paketindən dəyişdirilməyib.
