TAXDATA · 3 QAT BACKUP

Lokal backup qovluğunu seçin

Production təhlükəsizliyi üçün bu kompüterdə ayrıca backup qovluğu seçilməlidir. TaxData cari backupı və son 10 versiyanı burada saxlayacaq.

Məlumat qoruması: IndexedDB əsas nüsxədir, seçilən qovluq ikinci lokal nüsxədir, Supabase PostgreSQL isə 3 günlük şifrələnmiş qəza bərpa nüsxəsini saxlayır.
Qovluq seçmədən iş sahəsinə keçid tamamlanmır.

TAXDATA LOCAL AGENT

Agent quraşdırılsın?

e‑Taxes əməliyyatının bu kompüterdəki brauzer və internet üzərindən işləməsi üçün TaxData Local Agent bir dəfə quraşdırılmalıdır.

✓ Sayt üzərindən təsdiqQərarı burada verirsiniz. Quraşdırıcının içində B/X və ya əlavə seçim olmayacaq.
✓ Brauzer endirilmirMövcud Chrome, Edge, Brave, Chromium, Opera və ya Vivaldi istifadə olunur.
✓ Administrator hüququ tələb olunmurAgent istifadəçi səviyyəsində %LOCALAPPDATA%\TaxData daxilində qurulur; ayrıca watchdog və bərpa CMD-si saxlanılır.
✓ Java yalnız lazım olduqdaJava 21 yoxdursa yalnız agent üçün ayrıca private runtime quraşdırılır.
✓ Özünü bərpa edirAgent/JAR/start/watchdog və ya bərpa CMD-si silinsə çatışmayan hissələr yenidən yoxlanıb tamamlanır.
Windows təhlükəsizliyi: Bəli seçildikdə TaxData-Agent-Setup.cmd avtomatik endiriləcək. Brauzer təhlükəsizlik qaydasına görə endirilmiş proqramı özü işə sala bilməz; faylı Downloads bölməsindən bir dəfə açmağınız kifayətdir.
